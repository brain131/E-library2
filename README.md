# E-library
## project overview

E library is a web-based application that allows learners to search for books and access available reading materials online without physically visiting the school library.

## objective
To make it easier for anyone to access books online
To allow anyone to save books online and reade them at there own pace
## Features
Books can be searched online
Books can be saved
Saved books can be deleted
Book details can be viewed

# Technologies used
Html
Css
Javascript

# Future improvement
Database integration
Book categories and filtering
Administrator dashboard

# limitations
Book availability depends on google Books API
Not all books are free
